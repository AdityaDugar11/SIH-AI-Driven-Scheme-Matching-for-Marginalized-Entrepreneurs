# Design System

## 1. Philosophy
The design must evoke trust, transparency, and accessibility. Given the target demographic, the UI must not be overwhelming.

## 2. Core Tokens
- **Primary Color:** `#0F52BA` (Sapphire Blue - Trust)
- **Secondary Color:** `#2E8B57` (Sea Green - Success/Eligibility)
- **Warning Color:** `#D32F2F` (Red - Ineligible/Gaps)
- **Background:** `#F9FAFB` (Off-white)
- **Typography:** 'Inter', sans-serif. Use large, readable font sizes (minimum 16px for body text).

## 3. Components
- **Cards:** Rounded corners (xl), subtle shadows. Used for displaying schemes.
- **Progress Bars:** Used for profile completion and Scheme Match %.
- **Buttons:** Large, easily tappable areas (min 48px height for mobile).

## 4. Accessibility
- High contrast text.
- Screen-reader friendly aria-labels.
- Multi-lingual toggles prominently displayed.
