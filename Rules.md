# Coding Rules

1. **Clean Code:** Use meaningful variable names. Avoid deep nesting.
2. **Components:** Use functional React components with Hooks. Keep components small and modular (e.g., `SchemeCard.jsx`, `FilterChip.jsx`).
3. **Styling:** Strictly use Tailwind CSS utility classes. Avoid custom CSS unless absolutely necessary.
4. **Comments:** Comment complex AI matching logic in the backend. Do not over-comment standard UI components.
5. **Types:** If using TypeScript (recommended), define interfaces for `User`, `Scheme`, and `Partner`.
6. **Error Handling:** All API calls must have `try/catch` blocks and user-friendly error messages on the frontend.
